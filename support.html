A little help getting started.

Set up AI Follow, bring in a script, and find your pace. Impromptu is made for iPhone and iPad running iOS or iPadOS 26 or later.

Open, then start

Impromptu prepares local speech recognition when the app opens. Open a script from the library and tap Start once AI Follow is ready. The script follows your voice. Dragging the script, editing, or an audio interruption pauses prompting. Tap Start when you are ready to continue.

Getting AI Follow ready

AI Follow uses on-device English speech recognition on supported devices. The app prepares it at launch; the first setup may need an internet connection to download language assets from Apple. Keep the app open until preparation is complete. Preparation does not listen to you or move the script. Start begins a ready session and asks for microphone access if needed; it does not install models. If assets are unavailable or preparation fails, check the setup status. Prompting stays paused while your library and editor remain available.

If the microphone is unavailable

Open Settings, find Impromptu, and allow Microphone access. Return to the app and tap Start once AI Follow is ready. Check that your microphone is connected and that another app or call is not using it. After a route change or interruption, prompting stays paused until you start it again.

Bring a script

Use Import to choose TXT, Markdown, RTF, or DOCX from Files. Files must be 25 MiB or smaller. PDF is not supported. Your original file is unchanged. Review the imported text before using it.

Very long scripts may need to be split into smaller parts. The reading limit is about 200,000 characters, with some characters such as emoji counting as two. An oversized import is rejected; an oversized editor draft stays in the editor so you can shorten it. Your previous saved script is kept.

DOCX import reads main-document paragraphs, tables and textboxes. Headers, footers, footnotes, endnotes, comments, and words inside images are not included. Deleted tracked-change text is omitted. If those parts contain words you need to speak, put them into the document body or export a plain text copy first.

Common bullet and numbered lists keep visible markers. Indentation is simplified. Advanced Word numbering, custom restarts, picture bullets, and symbol fonts may be simplified or shown as standard bullets. If exact numbering matters, export a plain text copy from Word and review it before prompting.

RTF import keeps text and reading paragraphs through Apple's native text reader. Rich fonts, colors, and page layout are replaced by Impromptu's reading style. Markdown and DOCX headings remain recognizable in the imported script.

Make the script comfortable

Adjust text size, line spacing, margins, and reading-guide position in the appearance controls. Use Mirror with teleprompter glass. The script mirrors while the controls remain readable.

Keep a copy

Export a script as plain text or Markdown to a destination you choose. Markdown retains Impromptu's section labels and headings for compatible imports. A recovery message means the app found a damaged saved file; it preserves that file and uses a previous valid save when possible. If a save fails, keep your editor open and retry before leaving.
